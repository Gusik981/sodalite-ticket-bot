# Discord Ticket Bot (Python / discord.py 2.x)

Современный и функциональный тикет-бот для Discord серверов, созданный на Python с использованием интерактивных компонентов: постоянных кнопок (**Persistent Views**), выпадающих списков (**Select Menus**), модальных окон (**Modals**) и автоматической генерации HTML-транскриптов.

---

## 🌟 Основные возможности

- 📩 **Интерактивная панель создания тикетов**: отправка стильного меню со слэш-команды `/ticket-panel`.
- 📝 **Модальное окно**: пользователь вводит тему и подробности проблемы прямо в клиенте Discord перед созданием тикета.
- 🔒 **Приватные каналы**: канал виден только автору тикета и указанной роли технической поддержки (`Support Role`). Доступ для `@everyone` закрыт.
- ⚡ **Постоянные кнопки (Persistent Views)**: панель и кнопки управления работают даже после перезапуска бота без необходимости заново отправлять меню.
- 📜 **HTML-транскрипты**: при закрытии тикета генерируется веб-транскрипт переписки в тёмном стиле Discord с сохранением аватаров, вложений, эмбедов и меток времени.
- 🗃️ **Логирование и отправка в ЛС**: бот автоматически отправляет транскрипт в специальный канал логов и в личные сообщения создателю тикета.
- 👥 **Управление участниками**: удобные кнопки и команды `/ticket-add` и `/ticket-remove` для добавления участников в тикет.

## 🚀 Быстрый старт и установка

### 1. Создание бота в Discord Developer Portal
1. Перейдите на [Discord Developer Portal](https://discord.com/developers/applications).
2. Нажмите **New Application**, введите имя бота и нажмите **Create**.
3. Перейдите во вкладку **Bot** слева.
4. Нажмите **Reset Token** и скопируйте полученный токен.
5. Прокрутите вниз до раздела **Privileged Gateway Intents** и включите следующие галочки:
   - ✅ **Server Members Intent**
   - ✅ **Message Content Intent**
6. Сохраните изменения (**Save Changes**).

### 2. Настройка `config.json`
Откройте файл `config.json` в корне проекта и укажите ваши параметры:

```json
{
  "token": "СЮДА_ВСТАВЬТЕ_ТОКЕН_БОТА",
  "prefix": "!",
  "guild_id": 0,
  "support_role_id": 0,
  "ticket_category_id": 0,
  "log_channel_id": 0,
  "delete_delay_seconds": 5
}
```

- `token`: токен вашего бота.
- `guild_id`: (Опционально) ID вашего Discord-сервера. Если указан, слэш-команды обновляются мгновенно на этом сервере. Если `0`, команды регистрируются глобально (может занять до 1 часа для обновления в Discord).
- `support_role_id`: ID роли модераторов / техподдержки, у которых будет доступ к тикетам.
- `ticket_category_id`: ID категории, в которой будут создаваться каналы тикетов (если `0`, бот автоматически создаст категорию «📩 Тикеты»).
- `log_channel_id`: ID текстового канала, куда бот будет присылать транскрипты закрытых тикетов (если `0`, отправка в канал логов отключается).
- `delete_delay_seconds`: количество секунд до удаления канала после нажатия кнопки подтверждения закрытия (по умолчанию `5`).

> **Как скопировать ID роли, канала или сервера?**  
> В Discord перейдите в *Настройки пользователя -> Расширенные -> Режим разработчика (включить)*. Теперь при правом клике на сервер, роль или канал будет пункт «Копировать ID».

### 3. Установка зависимостей
Убедитесь, что установлен Python 3.10 или выше:
```bash
pip install -r requirements.txt
```

### 4. Запуск бота
```bash
python bot.py
```
При запуске в консоли отобразится ссылка-приглашение (**OAuth2 Invite URL**) с необходимыми правами:
- Управление каналами (`Manage Channels`)
- Просмотр каналов и отправка сообщений (`View Channel`, `Send Messages`)
- Встраивание ссылок и прикрепление файлов (`Embed Links`, `Attach Files`)
- Использование команд приложений (`Use Application Commands`)

Перейдите по ссылке в консоли и добавьте бота на свой сервер.

## 📋 Использование команд

| Команда | Описание | Доступ |
|---|---|---|
| `/ticket-panel` | Отправляет интерактивную панель с меню тикетов в текущий канал | Только Администраторы |
| `/ticket-add @пользователь` | Добавляет пользователя в текущий тикет | Внутри тикета |
| `/ticket-remove @пользователь` | Удаляет пользователя из тикета | Внутри тикета |
| `/ticket-close` | Завершает и закрывает текущий тикет с генерацией транскрипта | Внутри тикета |

Внутри каждого открытого тикета также доступны встроенные кнопки:
- 🔒 **Закрыть тикет** — открывает меню подтверждения закрытия.
- 📜 **Транскрипт** — немедленно выгружает HTML-файл с историей сообщений.
- ➕ **Добавить участника** — открывает модальное окно для ввода ID или упоминания.
- ➖ **Удалить участника** — открывает окно для удаления участника из канала.
